# TP Blog

Es un proyecto web desarrollado con Django. Principalmente se muestra el portfolio, el cual incluye la seccion de blog. En esta el admin publica sus posteos, los cuales tienen comentarios sin necesidad de un logim.


## Tecnologias utilizadas 

- HTML  
- Django
- Bootstrap 5.3.8
- GitHub
- CSS
- Python
- Font Awesome
- Google Fonts


## Como instalarlo

Debes tener python 3.12 o superior. Luego clonar el repositorio en el GitHub Desktop y abri el documento con tu editor de codigo.

- python -m venv venv
- .\venv\Scripts\Activate.ps1
- python -m pip install -r requirements.txt
- python manage.py migrate
- python manage.py runserver

- http://127.0.0.1:8000/
- http://127.0.0.1:8000/blog/
- http://127.0.0.1:8000/admin/
