# Eduardo De Turris — Portafolio Django

Proyecto web desarrollado con Django. Incluye una plantilla base (`base.html`) con tema claro/oscuro, navegación, footer y estilos personalizados en `base.css`.

## Tecnologías

- Django
- Bootstrap 5.3.8
- Font Awesome 6.7.2
- Google Fonts: Bebas Neue e Inter
- CSS personalizado con variables
